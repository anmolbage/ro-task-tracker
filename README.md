# RO Task Tracker

Task monitoring for the Regional Manager, RO Hazaribag: who has which task, what is overdue,
and whom to chase. Live at https://anmolbage.github.io/ro-task-tracker/

**Current state: clickable prototype.** Sample tasks are built in; anything you change is saved
only in that phone's browser. The Google Sheet backend, PIN login and sync come next, built from
`_template-pwa-sheets` as the other branch apps are.

Open the link on a phone, then browser menu → **Add to Home screen**.
